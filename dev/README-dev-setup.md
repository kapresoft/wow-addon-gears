## Developer Setup

### Sync With Kapresoft LibUtil (Sandbox)

Execute the following to sync the Kapresoft Lib Util Sandbox

```shell
sync-wow-lib-util-sandbox ./Gears/External/Lib
```

### Link LibPrettyPrint (Sandbox)

Link with the sandbox repo

```shell
ln -s ~/sandbox/github/kapresoft/wow/LibPrettyPrint/Libs/LibPrettyPrint ./Gears/ThirdParty/Libs/.
```
